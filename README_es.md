## 🎯 Descripción General

Este portfolio representa mi transición profesional hacia la Ingeniería de Software, combinando desarrollo backend moderno con más de 20 años de experiencia práctica en infraestructura electromecánica, electrónica y telecomunicaciones.

Mi enfoque técnico actual está orientado a **Java 21 LTS, Spring Boot 3, PostgreSQL, OCI Cloud, Linux, networking, IoT y sistemas de telemetría**.

El concepto central del portfolio es:

> **Construyendo el puente entre el software y la infraestructura energética**

El objetivo es conectar la ingeniería de software con sistemas industriales reales, transformando datos de campo y telemetría en información estructurada que pueda ser procesada mediante arquitecturas backend confiables.

## 🔬 Especialización Principal

### Digitalización Energética e Industrial

Mi orientación técnica se centra en conectar software backend moderno con activos físicos y datos industriales.

El objetivo es desarrollar sistemas capaces de:

- Recibir telemetría desde dispositivos de campo.
- Validar y estructurar datos de sensores.
- Exponer APIs REST confiables.
- Procesar información operacional.
- Conectar entornos Edge con infraestructura Cloud.
- Dar soporte a sistemas de monitoreo y mantenimiento predictivo.

Este enfoque combina ingeniería de software con experiencia práctica en diagnóstico y mantenimiento de sistemas físicos.

### 🛢️ Volve Energy Monitor

**Plataforma de Producción y Telemetría Industrial**

El proyecto utiliza el dataset industrial publicado por Equinor correspondiente al campo Volve, ubicado en el Mar del Norte.

- Java 21

- MQTT

- Arquitectura distribuida

https://github.com/P4154N0/volve-energy-monitor

**Objetivo:** Sector Energético de Calgary

## 🧩 Filosofía de Ingeniería

El portfolio está construido alrededor de un principio práctico:

> **Primero comprender el problema físico. Después diseñar el software que lo resuelve.**

Mi experiencia previa en telecomunicaciones, electrónica, infraestructura electromecánica y diagnóstico de campo constituye una base para comprender los sistemas más allá de la capa de software.

El objetivo no es simplemente escribir código, sino comprender cómo el software interactúa con infraestructura, datos, redes, dispositivos y entornos operacionales.
